# Q-team · Новорічний корпоратив

Лендинг (версія 3, фіолетово-жовта, за макетом у Figma від 06.11). Статичний сайт: `index.html` + `img/`.
Шари дизайну лежать в `img/v4/` і `img/v5/` (квіз, дошка безпеки, підкладки сценаріїв), фото ялинки в `img/p/`.
GitHub Pages: Settings → Pages → Deploy from branch `main`, папка `/ (root)`.

## Tilda

Блоки для Tilda лежать у `tilda/` (оновлюються командою `python3 tilda/build.py`):

- `0-short-embed.html` — найкоротший варіант: один блок T123, стилі й скрипт підтягуються з Vercel (`qteam.css`, `qteam.js`).
- `1-styles.html`, `2-markup.html`, `3-data.html`, `4-app.html` — те саме, розбите на чотири блоки T123 (додавати в цьому порядку, один під одним).

Картинки в обох варіантах беруться з Vercel, на Tilda їх вивантажувати не треба.
