# Q-team · Новорічний корпоратив 2027

Лендинг новорічних корпоративів Q-team, зібраний з макета у Figma.

## Що всередині

- `index.html` — уся сторінка: розмітка, стилі й скрипти в одному файлі
- `img/` — фони блоків, спрайт полароїдів для ялинки, зірка, фото для квізу, стрічка логотипів

## Як працює сторінка

- Макет зверстаний у ширині 1200 px і масштабується на всю ширину екрана
- Перший екран: полароїди падають і складаються в ялинку, потім з'являються зірка, «2027», текст і нижній ряд іконок
- Квіз: 3 питання, форма з ім'ям і телефоном, екран подяки. Форма поки не підключена до CRM
- Фонові «переживання» в другому блоці — справжній текст із SVG-обводками

## Публікація

Сторінка статична, тому її можна віддавати через GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
